# Cook Corner – Recipes Website

A learning project built with React to practise API integration and data fetching in a recipe website.

### What I learned
- Building reusable UI components with React
- Fetching and managing API data using RTK Query
- Handling asynchronous API requests
- Displaying dynamic recipe data from an external API
- Managing application state with Redux Toolkit

**Tech Stack:** React, JavaScript, Redux Toolkit, RTK Query, CSS
